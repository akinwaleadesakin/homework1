# F1 Cars Website

## Project Description

This project is a four-page website about Formula 1 cars. The website provides information about F1 car technology, different car parts, and how the cars compete in races.

The website was created using HTML and Sass.

## Pages

- Home
- Technology
- Car Parts
- Competition

## Technologies Used

- HTML
- Sass
- CSS
